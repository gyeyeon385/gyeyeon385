### 소개 · 關於我

한국어와 번체 중국어를 오가며, 일상에서 발견한 문제를 작고 신뢰할 수 있는 도구로 만듭니다. 특히 macOS와 iOS의 네이티브 경험, 입력 흐름, 개발 및 미디어 도구에 관심이 있습니다.

以韓文與繁體中文工作，喜歡把日常遇到的問題做成小巧、可靠的工具。關注 macOS 與 iOS 原生體驗、文字輸入流程，以及開發與媒體工具。

### 공개 작업 · 公開作品

**[TextInjector](https://github.com/gyeyeon385/TextInjector)**  
macOS용 SwiftUI 앱. CoreGraphics 키보드 이벤트로 Safari에 Unicode 텍스트를 입력하며, 공백·여러 줄·Tab 입력을 지원합니다. 현재 미리보기 버전입니다.

原生 macOS SwiftUI 工具，透過 CoreGraphics 鍵盤事件將 Unicode 文字輸入 Safari，支援空格、多行文字與 Tab。目前為預覽版。

**[DeepSeek Fatfish · Juvenile](https://github.com/gyeyeon385/deepseek-fatfish-juvenile-pet)**  
ChatGPT Work 캐릭터용 애니메이션 에셋 모음. 9가지 동작과 16개 시선 방향, 미리보기 및 품질 점검 자료를 포함합니다.

ChatGPT Work 角色動畫素材集，包含 9 種動作、16 個注視方向，以及預覽與品質檢查資料。
